# GIT Instructions Simplified

```bash
# For collaborators
git status --short                                  # 改之前
git add when/ && git commit -m "English message"    # 存档
git push                                            # 上传
git tag -a v1.1 -m "..." && git push origin v1.1    # 有实质变化时才打新版本
git checkout v1.0 -- when/                          # 随时回到基线

# For myself

git status --short                                  # 改之前
git add when/ && git commit -m "English message"    # 存档
git push                                            # 上传
git tag -a v1.1 -m "..." && git push origin v1.1    # 有实质变化时才打新版本
git checkout v1.0 -- when/                          # 随时回到基线
```
